# 실행 가이드

처음 한 번만 하면 된다. 끝나면 POS 창과 키오스크 창이 뜬다.

| 단계 | 할 일 | 다 되면 |
|---|---|---|
| 1 | 설치 확인 | 4가지가 다 있음 |
| 2 | Eclipse 프로젝트 만들기 | `DicePOS` 프로젝트 |
| 3 | 코드 넣기 | `src` 아래 `dicepos` 폴더 |
| 4 | DB 만들기 | Workbench에 테이블 17개 |
| 5 | 실행 | 잠긴 POS 창 |

## 1. 설치 확인

- JDK 17
- Eclipse IDE for Java Developers
- MySQL Community Server 8.0 + MySQL Workbench 8.0 (설치할 때 정한 **root 비밀번호를 적어 둔다**)
- `mysql-connector-j` jar (MySQL 홈페이지 → Connector/J → Platform Independent → ZIP을 받아 압축을 푼다)

## 2. Eclipse 프로젝트 만들기

1. 한글이 깨지지 않게: `Window` → `Preferences` → `General` → `Workspace` → `Text file encoding`에서 `Other` → `UTF-8` (Mac은 `Eclipse` → `Settings`)
2. `File` → `New` → `Java Project` → 이름 `DicePOS`, JRE `JavaSE-17`, `Create module-info.java file` 체크 **끄기** → `Finish`
3. 프로젝트 오른쪽 클릭 → `Build Path` → `Configure Build Path` → `Libraries` → `Classpath` → `Add External JARs…` → `mysql-connector-j-8.x.x.jar`

## 3. 코드 넣기

1. GitHub 저장소 첫 화면 → `Code` → `Download ZIP` → 압축을 푼다.
2. 압축 푼 폴더의 `src` 안 **`dicepos` 폴더**를 Eclipse 왼쪽 `src` 위로 끌어다 놓는다 → `Copy files and folders`
3. `dicepos.common` → `DBUtil.java`의 `"본인 root 비밀번호"`를 1단계에서 적어 둔 비밀번호로 바꾼다 → `Ctrl + S`

## 4. DB 만들기

1. Workbench에서 `Local instance` 접속
2. `File` → `Open SQL Script` → 압축 푼 폴더의 `DB/dicepos_schema.sql` → ⚡ (전체 실행)
3. 왼쪽 `SCHEMAS` 새로고침 → `dicepos` → `Tables`에 17개

이 파일을 다시 실행하면 DB가 처음 상태로 돌아간다(연습하다 꼬이면 다시 실행).

## 5. 실행

| 실행할 것 | 파일 (오른쪽 클릭 → `Run As` → `Java Application`) | 결과 |
|---|---|---|
| 연결 확인 | `dicepos.common.DBTest` | 콘솔에 `연결 성공! 메뉴 7개` |
| POS | `dicepos.main.PosMain` | 잠긴 POS 창 |
| 키오스크 | `dicepos.main.KioskMain` | 관리자 확인 → 룸 고르기 → 키오스크 창 (여러 개 띄워도 된다) |

**예시 계정**

| 아이디 | 비밀번호 | 이름 | 권한 |
|---|---|---|---|
| admin | admin1234 | 김지우 | 관리자 |
| seoyeon | admin1234 | 한서연 | 관리자 |
| minseo | staff1234 | 박민서 | 직원 |

**처음 써 보는 순서 (시연 순서로도 쓸 수 있다)**

1. POS → [출근] → `minseo` / `staff1234`
2. 테이블 현황 → Room 19 → [이용 시작] → 2명, 회원 검색 `5678` (김민수)
3. 키오스크 → `admin` / `admin1234` → Room 19 → 게임 추천, 음식 주문
4. POS 손님 주문받기 → [키오스크 새 주문] 확인 → 메뉴 버튼으로 추가 주문
5. 테이블 현황 → Room 19 → [이용 종료] → [결제하기] → 포인트·카드·현금 나눠 결제
6. 관리자 메뉴(예: 매출 관리) → 관리자 확인 `admin` / `admin1234`

## 막히면

| 나온 말 | 고치는 방법 |
|---|---|
| `No suitable driver` | 2단계 3번(jar 추가)을 다시 |
| `Access denied for user` | 3단계 3번 비밀번호가 틀림 |
| `Communications link failure` | MySQL이 꺼져 있음. Workbench로 접속되는지 확인 |
| `Unknown database 'dicepos'` | 4단계를 안 함 |
| 한글이 `???` | 2단계 1번(UTF-8)을 다시 |
| 빨간 줄 `cannot be resolved` | 3단계에서 `dicepos` 폴더가 `src` 바로 아래에 들어갔는지 확인 |
