# 팀원별 담당

발표 때 **자기 패키지의 파일은 각자 설명할 수 있게** 읽어 둔다.

## 누가 무엇을

| 담당 | 패키지 | 화면 | DB 작업 (DAO) | 내 테이블 |
|---|---|---|---|---|
| ① 김재민 | `staff`, `common.Session`·`AuthDialog` | `StaffPanel`(+`StaffDialog`, `MemoDialog`), `WorkSalaryPanel`, `SalesPanel`(+`BarChart`), `CheckDialog`(근무자·관리자 확인) | `StaffDAO`, `WorkLogDAO`, `SalaryDAO`, `SalesDAO`, `PasswordUtil` | staff, work_log, salary |
| ② 송하안 | `member`, `payment` | `MemberPanel`, `PaymentDialog`, `PaymentHistoryPanel` | `MemberDAO`, `PaymentDAO` | member, payment, payment_detail |
| ③ 김은별 | `game`, `main.KioskFrame`·`KioskMain`·`KioskScreen` | `GamePanel`, `GameRentalPanel`, `KioskRecommendPanel`, 키오스크 창 | `GameDAO`, `GameRentalDAO`, `RecommendDAO` | game, recommend, game_rental |
| ④ 박준영 | `menu`, `common`(DBUtil, UIUtil, DBTest, Refreshable), `main.PosMainFrame`·`PosMain` | `MenuPanel`, `PurchaseOrderPanel`, POS 메인 창 | `MenuDAO`, `PurchaseOrderDAO` | menu, purchase_order, purchase_order_detail |
| ⑤ 서윤채 | `table`, `common.FeeCalculator` | `TableStatusPanel`(+`TableCard`, `StartUsageDialog`, `EndUsageDialog`), `TableSettingPanel`, `FeeSettingPanel` | `CafeTableDAO`, `TableUsageDAO`, `FeeSettingDAO` | cafe_table, table_usage, fee_setting |
| ⑥ 김하진 | `order` | `OrderPanel`(+`NumberPadDialog`), `KioskOrderPanel`(+`MenuCard`, `CartItem`), `KioskStatusPanel` | `OrderDAO` | orders, order_detail |

DTO(테이블 한 줄을 담는 클래스)는 각자 패키지에 테이블마다 하나씩 있다. 예: `StaffDTO`, `MenuDTO`

## 서로 부르는 메서드

| 만든 사람 | 메서드 | 쓰는 사람 |
|---|---|---|
| ④ | `DBUtil.getConnection()`, `UIUtil.warn / info / confirm / won / toInt` | 전원 |
| ④ | `PosMainFrame.addScreen(이름, 화면, 관리자여부)` | 전원 (`PosMain`에서) |
| ① | `Session.getStaffId()`, `isAdminUnlocked()`, `getAdminId()` | ② ⑥ 결제·주문 직원, ④ 발주 |
| ① | `AuthDialog.confirmAdmin(화면)` | ④ 메인 창, ③ 키오스크 |
| ② | `PaymentDialog.open(화면, usageId)` | ⑤ 이용 종료 |
| ③ | `GameDAO.findAll()`, `increaseStock(con, …)`, `cancelReservations(con, …)` | ④ 발주·입고, ② 결제 |
| ④ | `MenuDAO.findByCategory(분류)`, `decreaseStock(con, …)`, `increaseStock(con, …)` | ⑥ 주문 |
| ⑤ | `FeeCalculator.perPerson(분)`, `total(분, 인원)` | ② 결제, ⑥ 이용 현황 |
| ⑤ | `TableUsageDAO.finish(con, usageId)` | ② 결제 |
| ⑥ | `OrderDAO.findDetailsByUsage(usageId)` | ② 결제 |

## 트랜잭션 (여러 테이블을 한 번에 바꾸는 곳)

`(Connection con, …)`을 받는 메서드는 부르는 쪽의 트랜잭션 안에서 실행된다. 받는 쪽은 `commit`·`rollback`·`close`를 하지 않는다.

| 트랜잭션 주인 | 하는 일 | 안에서 부르는 남의 메서드 |
|---|---|---|
| ② `PaymentDAO.pay` | 결제 + 결제 상세 + 포인트·등급 + 이용 종료 + 남은 예약 취소 | ⑤ `finish`, ③ `cancelReservations` |
| ④ `PurchaseOrderDAO.receive` | 발주 상태 '입고' + 메뉴 재고 + 게임 보유 수량 | ③ `increaseStock` |
| ⑥ `OrderDAO.saveOrder` 등 | 주문 + 주문 상세 + 메뉴 재고 | ④ `decreaseStock`, `increaseStock` |
| ③ `GameRentalDAO.returnGame` | 반납 + 다음 예약 '호출' | — |

## 계획서에 없어서 정한 것

- 회원 등급: 누적 결제 10만 원 이상 실버, 30만 원 이상 골드 / 적립: 카드·현금의 일반 1%, 실버 3%, 골드 5% (`PaymentDAO.gradeOf`, `earnRate`)
- 최저시급 10,320원 (`StaffDialog.MIN_WAGE`)
- 키오스크 룸은 사용가능한 룸 중에서 고른다 (이미 지정된 룸을 기억할 DB 칸이 없음)
