# 다이스 POS — 보드게임 카페 관리 프로그램

객체지향언어실습 기말 팀 프로젝트 (컴퓨터공학과 2학년 3반) · Java Swing + MySQL

## 주제

보드게임 카페는 일반 카페와 달리 **있었던 시간 × 인원만큼 이용료**를 받고, 음식값은 나갈 때 **한 번에 계산(후불)** 한다.
일반 카페 POS로는 이 계산이 안 돼서 직원이 입장 시간을 적어 두고 손으로 계산하다 실수가 생긴다.
또 처음 온 손님은 어떤 게임을 할지 몰라 직원에게 자주 묻고, 인기 게임은 다른 테이블이 쓰고 있어 기다린다.

그래서 **입장 → 주문 → 게임 대여 → 결제**를 한 프로그램에서 처리하고 이용료를 자동 계산한다.

| 화면 구분 | 쓰는 사람 | 하는 일 |
|---|---|---|
| 직원 화면 (POS) | 근무 중인 직원 | 입장 등록, 주문받기, 결제, 회원, 게임 대여·반납 |
| 관리자 화면 (POS) | 관리자만 (확인 팝업) | 직원·급여, 매출, 게임, 메뉴·발주, 테이블·요금 설정 |
| 키오스크 | 손님 (테이블마다 1대) | 게임 추천·대여 신청, 음식 주문, 이용 현황(예상 요금) |

POS와 키오스크는 같은 MySQL DB(`dicepos`, 테이블 17개)를 써서, 키오스크에서 주문하면 POS에 5초 안에 나타난다.

## 공부하는 순서

1. [실행 가이드](<문서/실행가이드.md>)대로 내 컴퓨터에서 실행해 본다. 내 화면을 직접 눌러 본다.
2. 내 **공부 문서**를 읽는다. 맨 위의 "AI에게 붙여 넣을 질문"과 거기 적힌 파일들을 AI(Claude, ChatGPT 등)에 같이 올려 설명을 듣는다.
3. 공부 문서 끝의 **예상 질문**에 AI 없이 답해 본다. 막히면 그 파일로 돌아간다.
4. 모르는 용어는 [기초 개념 정리](<문서/기초개념정리.md>), 다른 팀원과 주고받는 메서드는 [팀원별 담당](<문서/팀원별담당.md>)

※ 워드 파일(.docx)은 GitHub에서 미리보기가 안 되므로 내려받아 연다.
