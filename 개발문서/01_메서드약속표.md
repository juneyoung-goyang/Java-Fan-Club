# 01 메서드 약속표

서로의 코드를 부르는 곳이다. **이름, 받는 값, 돌려주는 값을 바꾸지 않는다.**
아직 안 만든 사람의 것은 [공통 코드](공통코드/src/dicepos)에 같은 모양의 임시 파일이 있어서, 먼저 끝낸 사람이 기다리지 않고 쓸 수 있다.

## Connection을 받는 메서드

`(Connection, …)`로 시작하는 메서드는 **부르는 쪽의 트랜잭션 안에서** 실행된다.
- 받는 쪽: 연결을 새로 열지 않고 받은 `con`을 그대로 쓴다. `commit`·`rollback`·`close`도 하지 않는다.
- 부르는 쪽: `setAutoCommit(false)` → 내 SQL + 남의 메서드 → `commit`, 예외가 나면 `rollback`

| 트랜잭션 주인 | 안에서 부르는 남의 메서드 |
|---|---|
| ② 결제하기 | ⑤ `finish`, ③ `cancelReservations` |
| ④ 입고 처리 | ③ `increaseStock` |
| ⑥ 주문 저장·취소 | ④ `decreaseStock`, `increaseStock` |

## 임시 파일을 진짜로 바꾸는 법

1. 자기 것 임시 파일을 지운다.
2. 같은 패키지, 같은 클래스 이름으로 진짜를 만든다.
3. 위 표의 메서드는 **같은 모양으로** 넣는다. 필드나 메서드를 더 추가하는 것은 괜찮다.
4. 완성하면 디스코드에 "○○ 진짜로 바꿨어요"라고 알린다.
