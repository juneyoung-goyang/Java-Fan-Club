## 3. 내 DTO 만들기

DTO는 테이블 한 줄을 담는 그릇이다. **테이블 칸 하나 = DTO 필드 하나**로 만든다.

**만드는 순서** (DTO마다 같다)
1. 내 패키지를 오른쪽 클릭 → `New` → `Class` → 아래 클래스 이름 → `Finish`
2. 표의 필드를 **위에서부터 순서대로** `private 타입 이름;`으로 적는다. 필드 순서가 곧 생성자의 매개변수 순서가 된다.
3. `Source` 메뉴 → `Generate Constructor using Fields…` → `Select All` → `Generate` (모든 필드를 받는 생성자)
4. `Source` 메뉴 → `Generate Getters and Setters…` → `Select Getters` → `Generate`
5. `LocalDateTime`·`LocalDate`에 빨간 줄이 나면 `Ctrl + Shift + O` (import 자동 추가)
6. `Ctrl + S`로 저장

> 타입 고르는 규칙: 숫자는 `int`, **비어 있을 수 있는 숫자(NULL)는 `Integer`**, 글자는 `String`, 날짜+시각은 `LocalDateTime`, 날짜만은 `LocalDate`, 0/1(예·아니요)은 `boolean`

### `dicepos.order.OrderDTO` ← `orders` (주문)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `orderId` | `int` | `order_id` INT | 주문 번호 |
| `usageId` | `int` | `usage_id` INT | 어느 테이블 이용 건의 주문인지 (후불제) |
| `staffId` | `Integer` | `staff_id` INT | 주문을 받은 직원 (키오스크 주문은 NULL) |
| `channel` | `String` | `channel` VARCHAR(10) | 주문 경로 (POS / 키오스크) |
| `orderTime` | `LocalDateTime` | `order_time` DATETIME | 주문 일시 |
| `totalAmount` | `int` | `total_amount` INT | 주문 금액 합계 (= 주문 상세 소계의 합) |
| `status` | `String` | `status` VARCHAR(10) | 상태 (접수 / 확인). 키오스크 주문은 '접수'로 들어오고 직원이 확인하면 '확인' |

### `dicepos.order.OrderDetailDTO` ← `order_detail` (주문 상세)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `orderDetailId` | `int` | `order_detail_id` INT | 주문 상세 번호 |
| `orderId` | `int` | `order_id` INT | 어느 주문의 상세인지 |
| `menuId` | `int` | `menu_id` INT | 주문한 메뉴 |
| `qty` | `int` | `qty` INT | 주문 수량 |
| `unitPrice` | `int` | `unit_price` INT | 주문 당시 단가 (menu.price에서 불러옴) |
| `subtotal` | `int` | `subtotal` INT | 소계 (qty × unit_price) |
| `menuName` | `String` | (없음, JOIN으로 가져옴) | 메뉴 이름. ② 결제가 씀 |

**다 되면**: DTO 파일마다 빨간 줄이 없다. 공통 코드도 빨간 줄이 없다(임시 파일을 지웠다면 같은 이름의 get 메서드를 만들었는지 확인).
