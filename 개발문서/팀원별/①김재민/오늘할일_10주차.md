## 3. 내 DTO 만들기

DTO는 테이블 한 줄을 담는 그릇이다. **테이블 칸 하나 = DTO 필드 하나**로 만든다.

**만드는 순서** (DTO마다 같다)
1. 내 패키지를 오른쪽 클릭 → `New` → `Class` → 아래 클래스 이름 → `Finish`
2. 표의 필드를 **위에서부터 순서대로** `private 타입 이름;`으로 적는다. 필드 순서가 곧 생성자의 매개변수 순서가 된다.
3. `Source` 메뉴 → `Generate Constructor using Fields…` → `Select All` → `Generate` (모든 필드를 받는 생성자)
4. `Source` 메뉴 → `Generate Getters and Setters…` → `Select Getters` → `Generate`
5. `LocalDateTime`·`LocalDate`에 빨간 줄이 나면 `Ctrl + Shift + O` (import 자동 추가)
6. `Ctrl + S`로 저장

> 타입 고르는 규칙: 숫자는 `int`, **비어 있을 수 있는 숫자(NULL)는 `Integer`**, 글자는 `String`, 날짜+시각은 `LocalDateTime`, 날짜만은 `LocalDate`, 0/1(예·아니요)은 `boolean`

### `dicepos.staff.StaffDTO` ← `staff` (직원)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `staffId` | `int` | `staff_id` INT | 직원 번호 |
| `loginId` | `String` | `login_id` VARCHAR(20) | 아이디 (중복 불가) |
| `password` | `String` | `password` VARCHAR(64) | 비밀번호 해시 (솔트를 붙여 SHA-256으로 바꾼 64자 값) |
| `salt` | `String` | `salt` VARCHAR(32) | 솔트 (직원마다 만든 무작위 값, 해시할 때 비밀번호에 붙임) |
| `name` | `String` | `name` VARCHAR(20) | 이름 |
| `phone1` | `String` | `phone1` VARCHAR(3) | 전화번호 1 |
| `phone2` | `String` | `phone2` VARCHAR(4) | 전화번호 2 |
| `phone3` | `String` | `phone3` VARCHAR(4) | 전화번호 3 |
| `role` | `String` | `role` VARCHAR(10) | 권한 (관리자 / 직원). 관리자만 관리자 화면을 열 수 있음 |
| `empType` | `String` | `emp_type` VARCHAR(10) | 고용 형태 (정규직 / 계약직 / 시간제) |
| `hourlyWage` | `Integer` | `hourly_wage` INT | 시급 (시간제만 입력, 나머지는 NULL) |
| `monthlyPay` | `Integer` | `monthly_pay` INT | 월 기본급 (정규직·계약직만 입력) |
| `hireDate` | `LocalDate` | `hire_date` DATE | 입사일 |
| `contractEnd` | `LocalDate` | `contract_end` DATE | 계약 종료일 (계약직만 입력) |
| `status` | `String` | `status` VARCHAR(10) | 재직 상태 (재직 / 퇴사) |
| `address` | `String` | `address` VARCHAR(100) | 주소 (선택 입력) |
| `workTime` | `String` | `work_time` VARCHAR(20) | 기본 근무 시간대 (예: 09:00~18:00, 선택 입력) |
| `memo` | `String` | `memo` VARCHAR(500) | 직원 메모 (선택 입력) |

### `dicepos.staff.WorkLogDTO` ← `work_log` (근무 기록)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `logId` | `int` | `log_id` INT | 근무 기록 번호 |
| `staffId` | `int` | `staff_id` INT | 근무한 직원 |
| `workDate` | `LocalDate` | `work_date` DATE | 근무 날짜 |
| `clockIn` | `LocalDateTime` | `clock_in` DATETIME | 출근 시각 |
| `clockOut` | `LocalDateTime` | `clock_out` DATETIME | 퇴근 시각 (근무 중이면 NULL) |
| `workMinutes` | `Integer` | `work_minutes` INT | 그날 실근무 시간(분) = 퇴근 − 출근 − 휴게. 퇴근할 때 계산해서 저장 |
| `note` | `String` | `note` VARCHAR(100) | 비고 (관리자가 시간을 고친 경우 그 사유) |

### `dicepos.staff.SalaryDTO` ← `salary` (급여)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `salaryId` | `int` | `salary_id` INT | 급여 번호 |
| `staffId` | `int` | `staff_id` INT | 급여를 받는 직원 |
| `payMonth` | `String` | `pay_month` CHAR(7) | 급여 월 (예: 2026-11). 같은 달 중복 확정 불가 |
| `workMinutes` | `int` | `work_minutes` INT | 그 달 누적 근무시간(분) = work_log 합계 |
| `baseAmount` | `int` | `base_amount` INT | 기본 급여 (시간제: 누적 시간 × 시급, 정규·계약: 월 기본급) |
| `extraAmount` | `int` | `extra_amount` INT | 추가 수당 (주휴수당 등, 관리자 입력, 기본값 0) |
| `totalPay` | `int` | `total_pay` INT | 지급액 (base_amount + extra_amount) |
| `status` | `String` | `status` VARCHAR(10) | 지급 상태 (미지급 / 지급완료) |
| `payDate` | `LocalDate` | `pay_date` DATE | 지급일 (지급 전이면 NULL) |

**다 되면**: DTO 파일마다 빨간 줄이 없다. 공통 코드도 빨간 줄이 없다(임시 파일을 지웠다면 같은 이름의 get 메서드를 만들었는지 확인).
