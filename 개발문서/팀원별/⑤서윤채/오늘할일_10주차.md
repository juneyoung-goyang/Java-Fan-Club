## 3. 내 DTO 만들기

DTO는 테이블 한 줄을 담는 그릇이다. **테이블 칸 하나 = DTO 필드 하나**로 만든다.

**만드는 순서** (DTO마다 같다)
1. 내 패키지를 오른쪽 클릭 → `New` → `Class` → 아래 클래스 이름 → `Finish`
2. 표의 필드를 **위에서부터 순서대로** `private 타입 이름;`으로 적는다. 필드 순서가 곧 생성자의 매개변수 순서가 된다.
3. `Source` 메뉴 → `Generate Constructor using Fields…` → `Select All` → `Generate` (모든 필드를 받는 생성자)
4. `Source` 메뉴 → `Generate Getters and Setters…` → `Select Getters` → `Generate`
5. `LocalDateTime`·`LocalDate`에 빨간 줄이 나면 `Ctrl + Shift + O` (import 자동 추가)
6. `Ctrl + S`로 저장

> 타입 고르는 규칙: 숫자는 `int`, **비어 있을 수 있는 숫자(NULL)는 `Integer`**, 글자는 `String`, 날짜+시각은 `LocalDateTime`, 날짜만은 `LocalDate`, 0/1(예·아니요)은 `boolean`

### `dicepos.table.CafeTableDTO` ← `cafe_table` (카페 테이블)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `tableNo` | `int` | `table_no` INT | 테이블 번호 |
| `tableName` | `String` | `table_name` VARCHAR(10) | 표시 이름 (예: Room 17) |
| `capacity` | `int` | `capacity` INT | 정원 (처음 등록·공사 시에만 수정, 인원 초과 검사) |
| `isActive` | `boolean` | `is_active` TINYINT(1) | 사용 여부 (1 사용가능 / 0 사용불가: 수리 등) |

### `dicepos.table.TableUsageDTO` ← `table_usage` (테이블 이용)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `usageId` | `int` | `usage_id` INT | 이용 번호 |
| `tableNo` | `int` | `table_no` INT | 이용한 테이블 |
| `memberId` | `Integer` | `member_id` INT | 회원 번호 (비회원은 NULL) |
| `people` | `int` | `people` INT | 이용 인원 |
| `startTime` | `LocalDateTime` | `start_time` DATETIME | 입장 시각 |
| `endTime` | `LocalDateTime` | `end_time` DATETIME | 퇴장 시각 (이용 중이면 NULL) |
| `status` | `String` | `status` VARCHAR(10) | 상태 (이용중 / 결제완료) |

### `dicepos.table.FeeSettingDTO` ← `fee_setting` (이용 요금 설정)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `feeId` | `int` | `fee_id` INT | 요금 번호 |
| `baseMinutes` | `int` | `base_minutes` INT | 기본 시간(분) |
| `basePrice` | `int` | `base_price` INT | 1인 기본요금 |
| `extraUnit` | `int` | `extra_unit` INT | 추가 요금 단위(분) |
| `extraPrice` | `int` | `extra_price` INT | 1인 추가요금 |
| `applyDate` | `LocalDate` | `apply_date` DATE | 적용 시작일 |

**다 되면**: DTO 파일마다 빨간 줄이 없다. 공통 코드도 빨간 줄이 없다(임시 파일을 지웠다면 같은 이름의 get 메서드를 만들었는지 확인).
