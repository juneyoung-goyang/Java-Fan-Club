## 3. 내 DTO 만들기

DTO는 테이블 한 줄을 담는 그릇이다. **테이블 칸 하나 = DTO 필드 하나**로 만든다.

**만드는 순서** (DTO마다 같다)
1. 내 패키지를 오른쪽 클릭 → `New` → `Class` → 아래 클래스 이름 → `Finish`
2. 표의 필드를 **위에서부터 순서대로** `private 타입 이름;`으로 적는다. 필드 순서가 곧 생성자의 매개변수 순서가 된다.
3. `Source` 메뉴 → `Generate Constructor using Fields…` → `Select All` → `Generate` (모든 필드를 받는 생성자)
4. `Source` 메뉴 → `Generate Getters and Setters…` → `Select Getters` → `Generate`
5. `LocalDateTime`·`LocalDate`에 빨간 줄이 나면 `Ctrl + Shift + O` (import 자동 추가)
6. `Ctrl + S`로 저장

> 타입 고르는 규칙: 숫자는 `int`, **비어 있을 수 있는 숫자(NULL)는 `Integer`**, 글자는 `String`, 날짜+시각은 `LocalDateTime`, 날짜만은 `LocalDate`, 0/1(예·아니요)은 `boolean`

### `dicepos.member.MemberDTO` ← `member` (회원)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `memberId` | `int` | `member_id` INT | 회원 번호 |
| `name` | `String` | `name` VARCHAR(20) | 이름 |
| `phone1` | `String` | `phone1` VARCHAR(3) | 전화번호 1 |
| `phone2` | `String` | `phone2` VARCHAR(4) | 전화번호 2 |
| `phone3` | `String` | `phone3` VARCHAR(4) | 전화번호 3 |
| `gender` | `String` | `gender` CHAR(1) | 성별 (M / F) |
| `grade` | `String` | `grade` VARCHAR(10) | 등급 (일반 / 실버 / 골드), 결제할 때 자동 변경 |
| `point` | `int` | `point` INT | 보유 포인트, 기본값 0 |
| `joinDate` | `LocalDate` | `join_date` DATE | 가입일 |

### `dicepos.payment.PaymentDTO` ← `payment` (결제)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `payId` | `int` | `pay_id` INT | 결제 번호 |
| `usageId` | `int` | `usage_id` INT | 결제한 테이블 이용 건 (한 이용 건은 한 번만 결제) |
| `staffId` | `Integer` | `staff_id` INT | 결제를 처리한 직원 |
| `memberId` | `Integer` | `member_id` INT | 결제한 회원 (비회원은 NULL) |
| `payTime` | `LocalDateTime` | `pay_time` DATETIME | 결제 일시 (연월일 시분초) |
| `totalAmount` | `int` | `total_amount` INT | 총 결제 금액 (= 결제 상세 소계의 합) |
| `cardAmount` | `int` | `card_amount` INT | 카드 결제 금액 |
| `cashAmount` | `int` | `cash_amount` INT | 현금 결제 금액 |
| `pointAmount` | `int` | `point_amount` INT | 포인트 결제 금액 (사용한 포인트) |
| `earnPoint` | `int` | `earn_point` INT | 이번 결제로 적립한 포인트 (비회원은 0) |

### `dicepos.payment.PaymentDetailDTO` ← `payment_detail` (결제 상세)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `payDetailId` | `int` | `pay_detail_id` INT | 결제 상세 번호 |
| `payId` | `int` | `pay_id` INT | 어느 결제의 상세인지 |
| `itemType` | `String` | `item_type` VARCHAR(10) | 항목 구분 (이용료 / 메뉴) |
| `menuId` | `Integer` | `menu_id` INT | 상품(메뉴) 번호. 이용료 줄은 NULL |
| `qty` | `int` | `qty` INT | 구매 수량 (이용료 줄은 이용 인원) |
| `unitPrice` | `int` | `unit_price` INT | 구매 단가 (메뉴는 주문 상세의 주문 당시 단가, 이용료는 1인 요금) |
| `subtotal` | `int` | `subtotal` INT | 상품별 결제 금액 소계 (qty × unit_price) |

**다 되면**: DTO 파일마다 빨간 줄이 없다. 공통 코드도 빨간 줄이 없다(임시 파일을 지웠다면 같은 이름의 get 메서드를 만들었는지 확인).
