## 3. 내 DTO 만들기

DTO는 테이블 한 줄을 담는 그릇이다. **테이블 칸 하나 = DTO 필드 하나**로 만든다.

**만드는 순서** (DTO마다 같다)
1. 내 패키지를 오른쪽 클릭 → `New` → `Class` → 아래 클래스 이름 → `Finish`
2. 표의 필드를 `private 타입 이름;`으로 적는다.
3. `Source` 메뉴 → `Generate Constructor using Fields…` → `Select All` → `Generate` (모든 필드를 받는 생성자)
4. `Source` 메뉴 → `Generate Getters and Setters…` → `Select Getters` → `Generate`
5. `LocalDateTime`·`LocalDate`에 빨간 줄이 나면 `Ctrl + Shift + O` (import 자동 추가)
6. `Ctrl + S`로 저장

> 타입 고르는 규칙: 숫자는 `int`, **비어 있을 수 있는 숫자(NULL)는 `Integer`**, 글자는 `String`, 날짜+시각은 `LocalDateTime`, 날짜만은 `LocalDate`, 0/1(예·아니요)은 `boolean`

### `dicepos.menu.MenuDTO` ← `menu` (메뉴)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `menuId` | `int` | `menu_id` INT | 메뉴 번호 |
| `name` | `String` | `name` VARCHAR(30) | 메뉴 이름 (중복 불가) |
| `category` | `String` | `category` VARCHAR(10) | 분류 (음료 / 간식 / 식사) |
| `price` | `int` | `price` INT | 판매 가격 |
| `stock` | `int` | `stock` INT | 재고 수량, 기본값 0 |
| `soldOut` | `boolean` | `sold_out` TINYINT(1) | 품절 여부 (1이면 주문 불가) |

### `dicepos.menu.PurchaseOrderDTO` ← `purchase_order` (발주)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `poId` | `int` | `po_id` INT | 발주 번호 |
| `staffId` | `Integer` | `staff_id` INT | 발주를 허락한 관리자 (관리자 확인을 통과한 직원 번호) |
| `supplier` | `String` | `supplier` VARCHAR(30) | 거래처 (선택 입력) |
| `orderDate` | `LocalDateTime` | `order_date` DATETIME | 발주 일시 |
| `totalAmount` | `int` | `total_amount` INT | 총 발주 금액 (= 발주 상세 금액의 합) |
| `status` | `String` | `status` VARCHAR(10) | 상태 (요청 / 입고 / 취소) |
| `receiveDate` | `LocalDateTime` | `receive_date` DATETIME | 입고 일시 (입고 전이면 NULL) |

### `dicepos.menu.PurchaseDetailDTO` ← `purchase_order_detail` (발주 상세)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `poDetailId` | `int` | `po_detail_id` INT | 발주 상세 번호 |
| `poId` | `int` | `po_id` INT | 어느 발주의 상세인지 |
| `itemType` | `String` | `item_type` VARCHAR(10) | 품목 구분 (메뉴 / 보드게임) |
| `menuId` | `Integer` | `menu_id` INT | 발주한 메뉴 (보드게임이면 NULL) |
| `gameId` | `Integer` | `game_id` INT | 발주한 보드게임 (메뉴면 NULL) |
| `qty` | `int` | `qty` INT | 발주 수량 |
| `unitCost` | `int` | `unit_cost` INT | 매입 단가 (같은 품목의 직전 발주 단가를 불러오고 수정 가능) |
| `amount` | `int` | `amount` INT | 발주 금액 (qty × unit_cost) |

**다 되면**: DTO 파일마다 빨간 줄이 없다. 공통 코드도 빨간 줄이 없다(임시 파일을 지웠다면 같은 이름의 get 메서드를 만들었는지 확인).
