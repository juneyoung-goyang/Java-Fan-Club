## 3. 내 DTO 만들기

DTO는 테이블 한 줄을 담는 그릇이다. **테이블 칸 하나 = DTO 필드 하나**로 만든다.

**만드는 순서** (DTO마다 같다)
1. 내 패키지를 오른쪽 클릭 → `New` → `Class` → 아래 클래스 이름 → `Finish`
2. 표의 필드를 `private 타입 이름;`으로 적는다.
3. `Source` 메뉴 → `Generate Constructor using Fields…` → `Select All` → `Generate` (모든 필드를 받는 생성자)
4. `Source` 메뉴 → `Generate Getters and Setters…` → `Select Getters` → `Generate`
5. `LocalDateTime`·`LocalDate`에 빨간 줄이 나면 `Ctrl + Shift + O` (import 자동 추가)
6. `Ctrl + S`로 저장

> 타입 고르는 규칙: 숫자는 `int`, **비어 있을 수 있는 숫자(NULL)는 `Integer`**, 글자는 `String`, 날짜+시각은 `LocalDateTime`, 날짜만은 `LocalDate`, 0/1(예·아니요)은 `boolean`

### `dicepos.game.GameDTO` ← `game` (보드게임)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `gameId` | `int` | `game_id` INT | 게임 번호 |
| `name` | `String` | `name` VARCHAR(50) | 게임 이름 |
| `genre` | `String` | `genre` VARCHAR(10) | 장르 (파티 / 가족 / 전략 / 추리 / 카드) |
| `minPlayer` | `int` | `min_player` INT | 최소 인원 |
| `maxPlayer` | `int` | `max_player` INT | 최대 인원 |
| `difficulty` | `int` | `difficulty` INT | 난이도 1~5 (★로 표시) |
| `playMin` | `int` | `play_min` INT | 평균 플레이 시간(분) |
| `stock` | `int` | `stock` INT | 보유 수량, 기본값 0 (입고하면 증가, 폐기하면 감소) |
| `status` | `String` | `status` VARCHAR(10) | 상태 (정상 / 부품누락 / 폐기) |
| `location` | `String` | `location` VARCHAR(10) | 진열 위치 (예: A-1) |

### `dicepos.game.RecommendDTO` ← `recommend` (게임 추천 기록)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `recId` | `int` | `rec_id` INT | 추천 번호 |
| `usageId` | `int` | `usage_id` INT | 추천을 받은 테이블 이용 건 |
| `memberId` | `Integer` | `member_id` INT | 추천받은 회원 (비회원은 NULL) |
| `gameId` | `int` | `game_id` INT | 추천한 게임 |
| `recTime` | `LocalDateTime` | `rec_time` DATETIME | 추천한 시각 |
| `chosen` | `boolean` | `chosen` TINYINT(1) | 손님이 이 게임을 골랐는지 (대여 신청·예약하면 1) |

### `dicepos.game.GameRentalDTO` ← `game_rental` (게임 대여·예약)

| 필드 이름 | 타입 | 테이블 칸 | 뜻 |
|---|---|---|---|
| `rentalId` | `int` | `rental_id` INT | 대여 번호 |
| `gameId` | `int` | `game_id` INT | 대여·예약한 게임 |
| `usageId` | `int` | `usage_id` INT | 어느 테이블 이용 건인지 |
| `status` | `String` | `status` VARCHAR(10) | 상태 (예약 / 호출 / 대여중 / 반납 / 취소) |
| `requestTime` | `LocalDateTime` | `request_time` DATETIME | 신청 시각 (예약 대기 순서의 기준) |
| `startTime` | `LocalDateTime` | `start_time` DATETIME | 대여 시작 시각 (게임을 받은 시각) |
| `returnTime` | `LocalDateTime` | `return_time` DATETIME | 반납 시각 (대여 중이면 NULL) |

**다 되면**: DTO 파일마다 빨간 줄이 없다. 공통 코드도 빨간 줄이 없다(임시 파일을 지웠다면 같은 이름의 get 메서드를 만들었는지 확인).
