# 00 시작 가이드

개발 첫날 **모든 팀원이 똑같이** 하는 준비다. 끝나면 내 컴퓨터에서 빈 POS 창이 뜨고 DB에 연결된다.
그다음은 [팀원별](팀원별) 폴더의 내 **오늘 할 일**로 넘어간다.

| 단계 | 할 일 | 다 되면 |
|---|---|---|
| 1 | 설치 확인 | 4가지가 다 있음 |
| 2 | Eclipse 설정, 프로젝트 만들기 | `DicePOS` 프로젝트 |
| 3 | 공통 코드 받아 넣기 | `src` 아래 `dicepos` 폴더 |
| 4 | DB 만들기 | Workbench에 테이블 17개 |
| 5 | 연결 확인 | "연결 성공! 메뉴 7개", 빈 POS 창 |

---

## 1단계. 설치 확인

없으면 설치한다.
- JDK 17
- Eclipse IDE for Java Developers
- MySQL Community Server 8.0 + MySQL Workbench 8.0 (설치할 때 정한 **root 비밀번호를 적어 둔다**)
- `mysql-connector-j` jar (MySQL 홈페이지 → Connector/J → Platform Independent → ZIP을 받아 압축을 푼다)

## 2단계. Eclipse 설정, 프로젝트 만들기

1. 한글이 깨지지 않게: `Window` → `Preferences` → `General` → `Workspace` → 아래 `Text file encoding`에서 `Other` → `UTF-8` → `Apply and Close` (Mac은 `Eclipse` → `Settings`)
2. `File` → `New` → `Java Project`
3. `Project name`: `DicePOS`, `JRE`: `JavaSE-17`, `Create module-info.java file` 체크 **끄기** → `Finish`
4. 프로젝트를 오른쪽 클릭 → `Build Path` → `Configure Build Path` → `Libraries` 탭 → `Classpath` 클릭 → `Add External JARs…` → `mysql-connector-j-8.x.x.jar` → `Apply and Close`

**다 되면**: 왼쪽에 `DicePOS`, 그 안에 `src`와 `Referenced Libraries`(jar)가 보인다.

## 3단계. 공통 코드 받아 넣기

공통 코드 = 모두가 같이 쓰는 뼈대(④ 박준영) + 아직 안 만든 팀원 기능의 **임시 파일**

1. GitHub 저장소 첫 화면 → 초록색 `Code` → `Download ZIP` → 압축을 푼다.
2. 압축 푼 폴더에서 `개발문서/공통코드/src` 안의 **`dicepos` 폴더**를 찾는다.
3. 그 `dicepos` 폴더를 Eclipse 왼쪽의 `src` 위로 끌어다 놓는다 → `Copy files and folders` → `OK`

**다 되면**: `src` 아래에 `dicepos.common`, `dicepos.main`, `dicepos.game`, `dicepos.menu`, `dicepos.order`, `dicepos.payment`, `dicepos.table`가 보인다.

| 들어 있는 것 | 누구 것 | 설명 |
|---|---|---|
| `DBUtil`, `UIUtil`, `DBTest`, `PosMainFrame`, `PosMain` | ④ 진짜 | 모두가 그대로 쓴다 |
| `Session`, `AuthDialog` | ① 임시 | ①이 진짜를 만들면 바뀐다 |
| `PaymentDialog` | ② 임시 | |
| `GameDTO`, `GameDAO` | ③ 임시 | |
| `MenuDTO`, `MenuDAO` | ④ 임시 | |
| `FeeCalculator`, `TableUsageDAO` | ⑤ 임시 | |
| `OrderDetailDTO`, `OrderDAO` | ⑥ 임시 | |

> 임시 파일은 **남이 아직 안 만든 기능을 내가 미리 쓸 수 있게** 모양만 맞춘 파일이다. 자기 것 임시 파일은 진짜를 만들 때 지우고 새로 만든다. 남의 임시 파일은 고치지 않는다. 자세한 약속은 [01 메서드 약속표](01_메서드약속표.md).

## 4단계. DB 만들기

1. Workbench에서 `Local instance` 접속
2. `File` → `Open SQL Script` → 압축 푼 폴더의 `개발문서/dicepos_schema.sql`
3. ⚡ 번개 아이콘 (전체 실행)
4. 왼쪽 `SCHEMAS`에서 새로고침 → `dicepos` → `Tables`

**다 되면**: 테이블 17개. 이 파일을 다시 실행하면 DB가 처음 상태로 돌아간다(연습하다 꼬이면 다시 실행).

**예시 계정** (출근·관리자 확인 시험용)

| 아이디 | 비밀번호 | 이름 | 권한 |
|---|---|---|---|
| admin | admin1234 | 김지우 | 관리자 |
| seoyeon | admin1234 | 한서연 | 관리자 |
| minseo | staff1234 | 박민서 | 직원 |

## 5단계. 연결 확인

1. `dicepos.common` → `DBUtil.java`를 연다.
2. `"본인 root 비밀번호"`를 1단계에서 적어 둔 비밀번호로 바꾼다(따옴표는 남김) → `Ctrl + S`
3. `DBTest.java`를 오른쪽 클릭 → `Run As` → `Java Application`
4. `dicepos.main` → `PosMain.java`를 오른쪽 클릭 → `Run As` → `Java Application`

**다 되면**: 콘솔에 `연결 성공! 메뉴 7개`, 그리고 왼쪽에 `직원 화면`·`관리자 화면 (잠김)` 제목만 있는 빈 POS 창이 뜬다(버튼은 11주차부터 생긴다).

**막히면**

| 나온 말 | 고치는 방법 |
|---|---|
| `No suitable driver` | 2단계 4번(jar 추가)을 다시 |
| `Access denied for user` | 5단계 2번 비밀번호가 틀림 |
| `Communications link failure` | MySQL이 꺼져 있음. Workbench로 접속되는지 확인 |
| `Unknown database 'dicepos'` | 4단계를 안 함 |
| 한글이 `???` | 2단계 1번(UTF-8)을 다시 |
| 빨간 줄 `cannot be resolved` | 3단계에서 `dicepos` 폴더가 `src` 바로 아래에 들어갔는지 확인 |

## 함께 일하는 규칙

1. **내 패키지만 고친다.** `dicepos.common`, `dicepos.main`을 바꾸고 싶으면 ④ 박준영에게 말한다.
2. **약속한 메서드 이름은 바꾸지 않는다.** 바꿔야 하면 디스코드에 먼저 알린다.
3. **코드 올리기**: 주마다 내 패키지 폴더(예: `dicepos/staff`)를 zip으로 묶어 디스코드에 올린다. ④가 합쳐서 공통 코드를 갱신한다. (GitHub 권한이 생기면 직접 올려도 된다)
4. **수업 끝날 때**: 디스코드에 이번 주 "다 되면" 캡처나 막힌 점을 한 줄 올린다.
5. **막히면**: 내 지침서 힌트 → 개념 정리 → 팀장에게 질문 순서로.
